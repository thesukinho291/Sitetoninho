# SiteToninho

Site institucional desenvolvido para apresentar o trabalho público de Toninho Corredor, com foco em esporte, cidadania, atendimento à população e ações sociais em Sorocaba.

O objetivo do projeto é reunir, em um único espaço, informações públicas sobre a trajetória do Toninho, o Jornal Atleta Cidadão, ações nos bairros e canais de contato com a população.

## Áreas públicas

- Página inicial
- Trajetória do Toninho Corredor
- Jornal Atleta Cidadão
- Ações sociais
- Agendamento de atendimento
- Contato

## Tecnologias

O projeto foi construído com React, TypeScript, Vite, Tailwind CSS, React Router e Supabase.

Imagens, textos e informações finais podem ser ajustados conforme o envio da equipe responsável pelo conteúdo.

Dados sensíveis e configurações privadas não fazem parte deste repositório.
